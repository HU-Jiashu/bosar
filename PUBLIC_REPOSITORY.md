Windows and macOS and the 4K feature-tour bundle, under *Releases*). The source code is not
published; Bosar ships as the installers, free for non-commercial use under the PolyForm
Noncommercial License 1.0.0 (see `LICENSE` and `docs/LICENSING.md`).
