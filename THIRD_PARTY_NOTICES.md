# Third-party notices

Bosar is the work of Jiashu Hu and is licensed to the public under the PolyForm Noncommercial
License 1.0.0 (see `LICENSE`; commercial licences from the author). This file records every piece
of third-party code that was **adapted** into the code base (the receiving file carries the
upstream copyright line and an `# Adapted from <repo>/<path> (<licence>)` header), every bundled
third-party **binary** and **data** file, the projects used as **reference only** (algorithms and
file formats re-implemented from the idea, cited in docstrings, no code copied), the online
services the application can call, and the **Python packages** an installer ships. The licence
texts the obligations require are in `packaging/notices/` and travel with every installer.

Rules: copy or adapt only from Apache-2.0 / MIT / BSD sources; GPL sources (MintPy,
ESA SNAP, PyAPS) are documentation only and run, if at all, as separate programs; a GPL module
imported in-process would put the whole program under the GPL. `tests/test_repo_hygiene.py`
checks that every `# Adapted from` header has a row below and vice versa.

This file is generated by `scripts/make_third_party_notices.py`; the first table is maintained in
`packaging/notices/adapted_and_bundled.md`, the package table comes from the installed metadata.

- `packaging/notices/dolphin-LICENSE.txt` — dolphin dual licence (BSD-3-Clause OR Apache-2.0, Caltech)
- `packaging/notices/LGPL-3.0.txt` — GNU Lesser General Public License 3.0 - Qt / PySide6 (shared libraries; the Qt sources: https://download.qt.io/official_releases/qt/)
- `packaging/notices/SNAPHU-copyright.txt` — SNAPHU copyright and permission notice (Stanford); the builds Bosar ships leave the CS2 solver out
